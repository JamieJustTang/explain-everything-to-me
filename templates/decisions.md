# 待决事项模板

适合“哪些事需要我决定”“有什么阻塞需要我处理”。只列从已读证据中确实存在的决定，不从 Agent 的下一步计划推造用户待办。

## 先说最重要的决定

先用一句话说明用户正在推进什么目标，再点出最紧迫的真实待决事项及它会影响哪条工作线；没有真实待决项时直接说明，并简述 Agent 可以自行推进的工作。目标若只是从会话归纳而来，要标明推断。

## 逐项说明

每项用简短文字回答：

- **要决定什么**：用用户听得懂的语言提出选择。
- **为什么现在要决定**：说明不决定会卡住什么，是否真的有期限。
- **关联目标**：说明这项选择服务什么目标；跨工作区的关联一起解释，不按目录重复列决定。
- **已知依据**：只给最相关的结论和 WorkRef，并说明尚未核实之处。
- **可选方向**：只有证据足以支持时才列选项与取舍；不要虚构二选一。

按影响与紧迫度排序。若用户只问进展，不要默认把本模板当成完整工作总结。

## 其他进展与范围

用一小段交代其他重要进展、实际时间范围和覆盖缺口，最后保留 Skill 规定的时间标记。
